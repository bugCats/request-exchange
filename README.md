# request-exchange 网页资源过滤器

#### 关键词

**浏览器插件** **浏览器扩展** **http拦截** **http转发** **请求转发** **JS脚本拦截** **实用工具**

#### 介绍
这是一款浏览器插件，主要是给后台开发使用。插件能够拦截页面内所有请求，可以根据预设的规则，将请求转发至本地服务或自定义地址。 

借助该插件，无需修改线上代码、无需本地部署前端项目，即可直接在真实线上网站中，调试本地接口与本地项目，所有修改仅作用于本地浏览器，完全不影响线上其他用户的正常访问。

详细 https://www.bugcat.cc/

#### 你在工作中是否经常遇到以下问题？

+ 每次都要手动收集参数，再通过swagger、postman等工具模拟发起请求？

+ 需要自己安装nginx、node环境，编译并启动前端项目，连接自己本地的后台服务？

+ 线上页面出现bug，需要本地复现并调试接口？

+ 不想改动线上代码，只想在本地临时替换接口？

+ 测试人员快速切换不同环境接口（测试/预发/本地）？

+ 打开某些页面，经常出现弹窗、牛皮癣广告、自动跳转到其他站点？

request exchange（网页资源过滤器） 统统可以帮你解决：

插件可以在你指定的网站运行，支持对指定网站进行精细化网络请求管理。插件能够实时拦截页面内所有网络请求，并根据你预设的规则，灵活将请求转发至本地服务或自定义地址。 借助该插件，你无需修改线上代码、无需部署测试环境，即可直接在真实线上网站中调试本地接口与本地项目，所有修改仅作用于本地浏览器，完全不影响线上其他用户的正常访问。

同时，插件支持配置域名黑名单，可一键拦截恶意脚本等第三方请求，没有烦人的弹窗，让网页更干净清爽！


********

1. 请求拦截与转发

    拦截页面 Ajax、Fetch、网页资源等所有网络请求，按规则转发至本地或自定义服务器。


2. 跨域与Referer防盗链

    修改请求头、响应头，自动允许跨域请求；解锁基于Referer的防盗链。


3. 线上网站本地调试

    直接在已上线网站调试本地后台项目，无需改动线上代码，无需部署测试环境。


4. 安全无侵入

    所有规则仅本地生效，不影响线上环境，不修改服务器，不影响其他用户访问。


5. 灵活规则配置

    支持按网址、接口路径匹配，精准控制哪些请求需要转发或拦截。


6. 轻量高效

    占用资源小，配置简单，可视化操作，启动即用，不拖慢浏览器速度。
